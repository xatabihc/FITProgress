# Аудит исходного FitProgressAI перед модернизацией 2.0

Дата: 2026-11-01. Проект не пересоздавался. Проверены Git status/diff, Gradle, manifest, README/status и все Kotlin-модули. Начальный commit: `b1d73e5`. В рабочей папке были изменения 1.0, untracked тесты/документация, `.idea` и сгенерированная Room schema. Они не сбрасывались.

## Факты на старте

- В отличие от прежнего README, существовал реальный APK v1.0, 108278904 байта, SHA-256 `ad3d2d7a25fc5e391a3065f5f27ea11a39b6ea46b1ab4f55d7bdfbc76c0de8ef`.
- APK имел applicationId `ru.fitprogress.ai`, min 29, target 35, versionCode 1. Его наличие не доказывало launch/GPS/Room smoke-тест.
- Зависимости Compose/Room/Location/MapLibre уже появились в локальном Gradle cache. Сгенерированы Room v1 Java и schema identity hash `63d071eabbf9c1eb45970e5d513cfeca`.
- Повторно выполнены исходные 30 JVM-тестов: пройдены.
- Повторная стандартная Gradle-сборка блокировалась read-only wrapper lock. Writable Gradle home не помог: daemon socket запрещён.
- ADB socket запрещён. Средство environment_status не было доступно в списке инструментов, network policy snapshot отсутствовал. Работа продолжена локальными инструментами без изменения сетевой политики.

## Что уже существовало

Каталог/редактор; Workout/SetEntry snapshots; Room JSON-таблицы; DataStore; конструктор и выполнение; календарь; 35 готовых расписаний; базовые рекомендации; GPS foreground service; MapLibre/локальная схема; история, аналитика, JSON/CSV. Архитектура MVVM/Repository сохранена.

## Найденные проблемы и результат

| Находка | Действие |
|---|---|
| Stopwatch/deadlines основаны на `currentTimeMillis` | Production-пути переведены на elapsedRealtime + boot ID; wall time оставлено для дат |
| Сигналы отдыха зависели от открытого Compose-экрана | Добавлен отдельный user-started foreground service |
| Нейтральный preview менял повторы; временные подходы получали бессмысленные повторения | Исправлена детерминированная логика, добавлена регрессия |
| Повторное подтверждение могло менять фактический результат и отдых | Idempotent complete по ID подхода |
| Импорт active таймеров переносил старые deadlines / терял остатки | Импорт на паузе с checkpoint-остатками, без anchors другого boot |
| location FGS запускался до проверки разрешения | Проверка до startForeground, обработка SecurityException |
| onDestroy старого RunService мог затронуть новую resumed generation | Проверка segment перед паузой |
| UI замены упражнения читал уже очищенный mutable ID | Захват неизменяемого target до async-операции |
| Room/Gson мог работать в main thread | Общая IO-обёртка Repository |
| Формы/выбор подхода терялись при rotation | rememberSaveable для полей и выбранных ID |
| Не было своего редактора недельных программ | Добавлен конструктор с preview, транзакцией и защитой истории |
| REPLACE мог повредить данные при конфликте program slot ID | Проверка конфликтов и запрет обычного save поверх active/done |
| Сохранённые определения программ отображались как пустые тренировки | Отдельная карточка/route программы; исполняемые шаблоны отфильтрованы |
| Выполненная тренировка могла попадать в аналитику по будущей плановой дате | Статистика/активность используют дату финиша; план и история расписания не переписываются |

## Что аудит не подтверждает

Не выполнялись Android smoke/UI/Room-тесты, реальная миграция установленного приложения, измерение батареи/памяти, force stop, блокировка экрана, реальный GPS и визуальная проверка. Статический анализ и компиляция не подменяют эти проверки.

Не проводилась профессиональная спортивная валидация 35 программ. Не заявляется индивидуальная безопасность или медицинская персонализация.
