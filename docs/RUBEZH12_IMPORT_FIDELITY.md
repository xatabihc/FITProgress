# Точный перенос программы Рубеж12 в FitProgressAI

Этот документ описывает расширение существующего JSON `schemaVersion: 1`. Все старые JSON сохраняют совместимость.

## Упражнение

Поля `name`, `sets`, `reps`, `seconds`, `weightKg`, `restSeconds` остались прежними.

Дополнительные, необязательные поля:

- `distanceMeters`: числовая дистанция **на один подход** в метрах (не километрах);
- `target`: исходная строка цели из Рубеж12, например «3 × 400 м, отдых 90 с»;
- `note`: исходное пояснение к упражнению;
- `setDetails`: массив с точными параметрами каждого планового подхода. Если указан, длина массива должна совпадать с `sets`.

Пример:

```json
{
  "schemaVersion": 1,
  "name": "Рубеж12",
  "weeks": 1,
  "days": [{
    "week": 1,
    "weekday": 2,
    "title": "Интервальный бег",
    "exercises": [{
      "name": "Интервалы 400 м",
      "sets": 2,
      "reps": 0,
      "distanceMeters": 400,
      "restSeconds": 90,
      "target": "2 × 400 м, отдых 90 с",
      "setDetails": [
        {"reps": 0, "distanceMeters": 400, "restSeconds": 90},
        {"reps": 0, "distanceMeters": 450, "restSeconds": 90}
      ]
    }]
  }]
}
```

Нельзя выдумывать повторы, дистанцию или признак выполнения, если их нет в исходных данных.
Плановые тренировки создаются со статусом `planned`. Значения, введённые в поле результата Рубеж12, ещё не доказывают факт выполнения. Импорт завершённой истории должен быть отдельным действием с проверкой дат и признаков завершения.

## Проверка перед переносом

1. Сохранить оригинальный `rubezh12_extracted_source.json` и старую базу FitProgressAI.
2. Посчитать и сопоставить все 84 занятия и число упражнений в исходном и новом JSON.
3. Проверить для каждого занятия: порядок, название, каждый подход, повторения, секунды, метры и отдых.
4. Если в исходнике есть непонятные поля, остановить импорт и явно показать предупреждения, а не подменять их значениями по умолчанию.
5. Не добавлять программу повторно, если она уже была импортирована — это создаст дубли.

Для полного конвертера необходим реальный файл `rubezh12_extracted_source.json` с устройства пользователя. Текущие изменения расширяют **принимающий формат** и не заявляют, что предыдущий файл на телефоне автоматически стал точным.
