# Changelog

## 2.1-dev — 2026-11-01

Цель — стабильная 2.1; выпуск пока development, пока не пройдены Android runtime/upgrade проверки.

- Персональные цели: шесть типов, несколько целей, сроки, реальный прогресс/история, фильтры источника бега, архив.
- Необязательный дневник энергии, усталости, сна, болезненности, восстановления и боли.
- Adaptive Coach: шесть вариантов, две недели истории и актуальный дневник, safety gates, конкретный preview, повторная проверка и атомарное применение/защита от повторов.
- Расширенная аналитика и сравнение равных периодов, интерактивный выбор дат, основная мышечная группа, оценочный e1RM с явной маркировкой.
- Акцентные цвета, отключение интернет-карты, опциональные плановые напоминания, сигналы GPS-километров; атомарные настройки DataStore.
- GPS timestamps на монотонных часах, freshness без ложной потери сигнала на месте, контроль разрешения/провайдера, обновление wake lock до expiry, отказ от mock/неопределённой точности.
- Редактор 1–52 недель: прямой переход, повтор до конца, удаление подходов, порядок упражнений, отдых/суперсеты/заметки.
- FitTestRunner изолирует UI-фикстуры от production базы/профиля; очистка требует подтверждённого тестового режима, старый test APK архивирован.
- Room v2 + явная миграция 1→2 только добавлением personal_records; прежние таблицы истории сохранены.
- Backup v3 для целей/дневника/Coach, чтение v1/v2, проверка экспорта до записи, защита импорта от скрытых активных demo/manual.
- 102 JVM-теста пройдены, включая SQL миграции на 10 000 записей. 15 Android-тестов компилируются, но не исполнены.
- Новый APK 2.1-dev собран локальными SDK-инструментами с регенерацией Room; обычный Gradle/Lint и запуск на устройстве остаются заблокированы средой.


## 2.0-dev — 2026-11-01

Частичная модернизация существующего проекта; не завершённая версия Ultimate.

### Добавлено

- `SessionTimers`/`RunTimers`: монотонные часы с boot ID, checkpoints, пауза/продолжение и восстановление.
- WorkoutTimerService: уведомление, фоновые сигналы отдыха/временного этапа, управляемые звук/вибрация, ограниченный wake lock.
- Расширенные параметры подходов: 11 типов, дистанция, отдельный отдых, RPE/RIR, комментарий.
- Добавление подходов и перестановка во время занятия, замена невыполненного упражнения, копирование прошлого результата.
- Конструктор программ 1–52 недели: упражнения по дням, восстановление, копирование недели, перенос дня, блоки, разгрузка, сдвиг расписания, preview и атомарное применение будущего плана.
- Ручной ввод беговой дорожки с явным отделением от GPS; оценка времени движения по GPS.
- Версионированная JSON-копия v2 с программами и новыми полями; чтение v1; расширенный CSV.
- Воспроизводимая offline-компиляция/упаковка на основе ранее разрешённых Gradle artifacts.
- Дополнительные unit/Room/UI-проверки и документация аудита.

### Исправлено

- Нейтральная рекомендация больше не увеличивает повторения; временные подходы не получают лишних повторений.
- Повторная отметка подхода не заменяет результат и не перезапускает отдых.
- Импортированные таймеры не используют clock anchors другого устройства и сохраняют checkpoint-остатки.
- Проверка геолокации выполняется до запуска location foreground; SecurityException обрабатывается.
- Старый GPS-сервис при уничтожении не ставит на паузу новую resumed generation.
- Замена упражнения захватывает ID до очистки состояния диалога.
- Редакторы подходов/метаданных сохраняют состояние при конфигурационных изменениях.
- Сериализация и транзакционные операции Repository выполняются вне UI-потока.
- Конфликт ID при применении программы не может перезаписать чужое занятие.
- Активные/завершённые занятия защищены от перезаписи через обычный save.
- Крупные показатели бега/главной складываются вертикально для узких экранов.

- Аналитика выполненных занятий использует фактическую дату финиша, сохраняя плановую дату для календаря/выполнения плана.

### Проверки

- 58 JVM-тестов выполнены, все пройдены.
- Полный Kotlin/Compose и Room-generated Java скомпилированы локальным инструментом.
- Android-тесты компилируются; исполнения на устройстве не было.
- Новый debug APK упакован SDK tools, подписан, проверен apksigner/zipalign.
- Стандартный Gradle build, Lint, ADB и Git commits заблокированы ограничениями среды.
