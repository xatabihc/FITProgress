# Changelog

## 3.0-dev — MapLibre и GPS-маршрутизация, 2026-11-02

- Последующая доработка: маршрутный matcher учитывает предыдущий участок и продвижение, отклонение подтверждается тремя точными fixes, reroute ограничен тремя попытками/двухминутным cooldown на пробежку; камера GPS-follow и локальный маршрутный preview работают отдельно от доступности tiles.
- Добавлен ручной адресный поиск Nominatim без autocomplete, с session cache, общей задержкой запросов и предупреждением о передаче адреса геокодеру. Круговой маршрут пробует до трёх дорожных вариантов с ограниченной обработкой no-route.
- Добавлены JVM regression tests для пересечений, точности фиксов, reroute gate и геокодера; текущий domain suite — 146 tests. В build outputs обнаружены более поздние стандартные Gradle результаты: 140 unit tests, Lint 0 errors/38 warnings и успешный assembleDebug. Последние диагностические логи и Android UI test добавлены после того APK и ещё требуют компиляции.

- Добавлен экран планирования маршрута: режимы бег/ходьба/велосипед, выбор старта/финиша касанием карты или координатами, промежуточные точки и примерный круговой маршрут на целевую длину.
- Добавлен configurable Valhalla `/route` backend с русскими maneuver instructions, альтернативными вариантами для пары точек, ограничением частоты и явной обработкой сетевых/HTTP/no-route ошибок. При недоступности backend straight-line маршрут не подменяет реальный, а GPS-запись продолжает работать отдельно.
- Карта MapLibre показывает OSM tiles, атрибутированный GPS track, геометрию запланированного пути, маркеры и последнюю фактическую позицию. В активном беге отображается остаток, отклонение и точка входа в ручное перестроение.
- Добавлены избранные маршруты через существующую personal_records таблицу, повторный выбор, GPX import/export; GPS run detail позволяет экспортировать фактический трек и сохранить его как маршрут.
- Существующая Room схема не менялась. Backup v4 переносит избранные маршруты и читает v1–v3. Ключ пользователя/подпись не изменялись кодом; фактическую совместимость обновления подтверждает только сравнение сертификата APK.
- Добавлены unit tests RouteMath, GPX, Valhalla network/request, сохранения маршрутов/backup; точный результат смотрите в `TESTING.md` после завершения полного Gradle цикла.
- Ограничения: endpoint сообщества best-effort, без SLA/offline; для публикации требуется уведомление Valhalla maintainers или собственный backend. OSM standard tiles запрещают bulk/offline prefetch. Нет address search, voice navigation и автоматического фонового reroute.

## 2.0-dev — 2026-11-01

Частичная модернизация существующего проекта; не завершённая версия Ultimate.

### Добавлено

- `SessionTimers`/`RunTimers`: монотонные часы с boot ID, checkpoints, пауза/продолжение и восстановление.
- WorkoutTimerService: уведомление, фоновые сигналы отдыха/временного этапа, управляемые звук/вибрация, ограниченный wake lock.
- Расширенные параметры подходов: 11 типов, дистанция, отдельный отдых, RPE/RIR, комментарий.
- Добавление подходов и перестановка во время занятия, замена невыполненного упражнения, копирование прошлого результата.
- Конструктор программ 1–52 недели: упражнения по дням, восстановление, копирование недели, перенос дня, блоки, разгрузка, сдвиг расписания, preview и атомарное применение будущего плана.
- Ручной ввод беговой дорожки с явным отделением от GPS; оценка времени движения по GPS.
- Версионированная JSON-копия v2 с программами и новыми полями; чтение v1; расширенный CSV.
- Воспроизводимая offline-компиляция/упаковка на основе ранее разрешённых Gradle artifacts.
- Дополнительные unit/Room/UI-проверки и документация аудита.

### Исправлено

- Нейтральная рекомендация больше не увеличивает повторения; временные подходы не получают лишних повторений.
- Повторная отметка подхода не заменяет результат и не перезапускает отдых.
- Импортированные таймеры не используют clock anchors другого устройства и сохраняют checkpoint-остатки.
- Проверка геолокации выполняется до запуска location foreground; SecurityException обрабатывается.
- Старый GPS-сервис при уничтожении не ставит на паузу новую resumed generation.
- Замена упражнения захватывает ID до очистки состояния диалога.
- Редакторы подходов/метаданных сохраняют состояние при конфигурационных изменениях.
- Сериализация и транзакционные операции Repository выполняются вне UI-потока.
- Конфликт ID при применении программы не может перезаписать чужое занятие.
- Активные/завершённые занятия защищены от перезаписи через обычный save.
- Крупные показатели бега/главной складываются вертикально для узких экранов.

- Аналитика выполненных занятий использует фактическую дату финиша, сохраняя плановую дату для календаря/выполнения плана.

### Проверки

- 58 JVM-тестов выполнены, все пройдены.
- Полный Kotlin/Compose и Room-generated Java скомпилированы локальным инструментом.
- Android-тесты компилируются; исполнения на устройстве не было.
- Новый debug APK упакован SDK tools, подписан, проверен apksigner/zipalign.
- Стандартный Gradle build, Lint, ADB и Git commits заблокированы ограничениями среды.
