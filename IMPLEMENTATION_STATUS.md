# FitProgressAI 3.0-dev — поэтапная реализация, 2026-11-02

Работа идёт в существующем проекте и branch `main`, без очистки базы и Git-истории. Application ID прежний; versionCode 6, versionName 3.0-dev. Схема Room осталась v2.

## Текущий этап: офлайн-каталог и проверяемая база

- 14 исходных русских упражнений + 871 валидная запись из 876 в snapshot free-exercise-db; 5 записей без ID/имени/целевой мышцы/техники не показываются. Источник, ревизия и Unlicense зафиксированы в asset; оригинальные шаги на английском. Источник не проходил отдельный тренерский аудит, фотографии не включены.
- Поиск частичных слов с ё/е, русских/английских названий, оригинальных мышц/оборудования/техники; фильтры группы, equipment, level. Создание/edit пользователя и прежний Room JSON сохранены.
- 18 расписаний/шаблонов с отдельными силовыми днями и заметками прогрессии заменили автогенерацию 35 одинаковых вариантов. ID прежних программ оставлены там, где они используются, а даты и завершённые workouts не переписываются.
- 128 JVM tests реально пройдены (включая SQLite migration, search, run-launch regression, plan structure). Dataset static validator прошёл. Kotlin/Compose/Room javac Android compilation и компиляция 24 Android test sources прошли. Инструментальные tests не запускались.
- APK собирается доступным SDK fallback, не clean Gradle. Пакет содержит asset и лицензионную атрибуцию; актуальные APK metadata/fingerprints в `docs/verification/v3.0/`.
- Обычный `./gradlew assembleDebug testDebugUnitTest lintDebug` остановлен на read-only distribution lock; daemon Gradle также ранее отказывал открывать socket. Android shell-команды заблокированы; ADB показал зарегистрированное устройство только через devices list. Установка, real map/GPS, миграция на устройстве, Compose visual check не проведены.

## Известные крупные ограничения

Маршрутизация между стартом/финишем и офлайн-карты не реализованы; текущая карта показывает GPS track, online OSM raster с fallback-схемой. Библиотека содержит не 60 программ и не покрывает каждый уровень для каждого направления. Только часть англоязычных упражнений имеет русское название; все исходные instructions сохранены на английском и явно обозначены. Не все движения имеют альтернативы/ошибки/раздельные мышцы/медиа.

Следующий порядок: получить полноценный Android/Gradle smoke test на разрешённом устройстве; расширить карточки/перевод и удобные избранные фильтры; довести библиотеку программ + JSON/CSV template import; затем интерактивная карта/routes. Не обозначать 3.0 как готовый профессиональный релиз до этих проверок.

## Данные при обновлении

`MIGRATION_1_2_SQL` создаёт только новую таблицу. Room-generated schema v2 и v1 хранятся в `app/schemas/ru.fitprogress.ai.FitDatabase/`. JVM JDBC-тест сравнивает прежние entity schema и каждое старое значение упражнений/тренировок/маршрутов. Profile/DataStore имя файла и ключи не менялись; новые поля имеют defaults. Добавлен отдельный Android-тест чтения старых ключей и атомарных изменений.

Код не переименовывает ID упражнений/истории и не выполняет удаление базы. Новая nullable muscleGroup сохраняется только в новых snapshots; старые данные остаются читаемыми. GPS-поля elapsed/boot nullable для старых точек. Active sessions сохраняют прежние правила: после прерывания GPS — пауза, после другого boot — checkpoint без выдуманного времени.

**Не подменять этими доказательствами тест реального APK upgrade.** До обновления телефона экспортировать копию, проверить тот же сертификат, установить `-r` без очистки. Старое приложение с Room v1 не предназначено для открытия базы v2.
