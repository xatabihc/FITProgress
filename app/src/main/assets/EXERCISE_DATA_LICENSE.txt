Offline exercise data

The dataset README credits the original exercise database by Ollie Jennings. This application includes the textual exercise records, not the source image files. Names, equipment, and instruction wording may be English; the interface marks the source language and translates available muscle/equipment labels. Five source records without required core fields are skipped at load time.
