# FitProgress 3.1 RC2

Для подключённого Samsung используйте **`FitProgress-3.1-rc2-QA.apk`**. Он установлен как **FitProgress QA 3.1**, история и профиль перенесены из прежнего приложения. Дальнейшие записи выполняйте в QA; старая установка сохранена отдельно и не синхронизируется с QA.

- QA APK подписан существующим локальным debug-ключом; повторная установка `adb install -r` сохраняет его данные.
- `*-local-debug.apk` и `*-CI-incompatible.apk` имеют обычный package ID и несовместимую со старой установкой подпись. Они предназначены для диагностики, а не обновления старого приложения.
- `*-QA-tests.apk` — только инструментальные тесты. Файлы RC1 сохранены как предыдущие артефакты.

Все сборки debug, не production release. [Суммы](SHA256SUMS), [подробный итог и ограничения](../docs/RELEASE-3.1-RC2.md). APK исключены из Git.
